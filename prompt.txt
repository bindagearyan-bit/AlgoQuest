CRITICAL PLACEMENT/PROGRESSION LOGIC RULES (must be enforced in backend, not just UI):
1. If user selects "Beginner" at signup → ALWAYS start at Level 1, Sublevel 1.1, Stage 1. No placement quiz, no skipping. Beginners must build confidence with simple wins first.
2. If user selects "Intermediate" → show placement quiz. Based on score, unlock Levels up to where they tested well, BUT user must still start at Stage 1 (Theory) of whatever sublevel they land on — cannot jump directly into Medium/Hard/Boss stages. They CAN "test out" of a sublevel entirely via an optional challenge exam.
3. If user selects "Advanced" → harder placement quiz, can unlock up to Level 5. Same rule: must start each sublevel at Stage 1, but can move fast since stages are quick for them.
4. WITHIN every sublevel, regardless of user's overall level, difficulty MUST progress: Theory → Visualization → Dry Run → Guided Example → Easy → Medium → Quiz → Boss. Never show Medium/Hard as a user's first interaction with a new concept. This is a hard rule for the recommendation engine — no exceptions.
5. "Test Out" feature: at the start of any locked-but-reachable sublevel, show an optional "Skip Test" (3 hard questions). Passing all 3 skips the sublevel and awards XP; failing even one keeps them in normal Stage 1-8 progression — no penalty.
6. Track per-user "confidence score" per topic (0-100, calculated from quiz/problem accuracy + time taken). If confidence score < 60% after completing a sublevel, auto-generate an extra practice stage before allowing progress to next sublevel.

3. FULL DSA CURRICULUM — STRUCTURED AS LEVELS → SUBLEVELS → STAGES
====================================================
Structure: MAIN LEVEL (big topic group) → SUBLEVEL (one specific concept) → STAGES (micro-progression: Learn → Easy → Medium → Hard → Boss)

Every SUBLEVEL must follow this exact internal stage order (unlocked sequentially, cannot skip):
  Stage 1: THEORY (concept explained with analogy + diagram, no code yet)
  Stage 2: VISUALIZATION (watch animated demo, click "Got it" to proceed)
  Stage 3: DRY RUN PRACTICE (predict variable states/output — 2-3 questions, builds intuition before coding)
  Stage 4: GUIDED CODE EXAMPLE (starter code mostly filled, user fills 1-2 blanks — confidence builder)
  Stage 5: EASY PROBLEM (1 problem, basic application of concept)
  Stage 6: MEDIUM PROBLEM (1 problem, slight twist/combination with previous concept)
  Stage 7: QUIZ (3-5 MCQs on theory/complexity)
  Stage 8: BOSS CHALLENGE (1 harder problem combining 2+ concepts learned so far — unlocks next sublevel + bonus XP + badge)

A user CANNOT jump to Stage 5 without completing Stages 1-4. A user CANNOT access Medium problems without clearing Easy first. This mimics Duolingo's progression — repetition with increasing difficulty, never a sudden jump.

---

LEVEL 1 — FOUNDATIONS (🔥 Starter World)
  1.1 What is an Algorithm? Time & Space Complexity (Big O via real-life analogies)
  1.2 Arrays Basics (declaration, traversal, insertion, deletion)
  1.3 Array Two-Pointer Technique
  1.4 Sliding Window Technique
  1.5 Prefix Sum
  1.6 Strings Basics (traversal, immutability, basic operations)
  1.7 Basic Math for DSA (GCD/LCM, primes, sieve)
  1.8 Recursion Basics (factorial, fibonacci — visualize call stack)
  1.9 Bit Manipulation Basics
  🏆 Final Boss: Mixed problem combining arrays + recursion

LEVEL 2 — LINEAR STRUCTURES
  2.1 Singly Linked List (create, traverse, insert, delete)
  2.2 Doubly & Circular Linked List
  2.3 Linked List Advanced (reverse, cycle detection - Floyd's)
  2.4 Stack Basics (array & linked list implementation)
  2.5 Stack Applications (balanced parentheses, monotonic stack)
  2.6 Queue Basics (simple, circular)
  2.7 Deque & Priority Queue
  2.8 Hashing Basics (hash map/set, collision handling)
  🏆 Final Boss: Stack + queue combo problem (e.g., LRU cache intro)

LEVEL 3 — NON-LINEAR STRUCTURES
  3.1 Binary Trees Basics (structure, terminology)
  3.2 Tree Traversals (inorder, preorder, postorder, level order) — heavy visualization
  3.3 Binary Search Tree (insert, delete, search)
  3.4 Balanced Trees Intro (AVL rotations concept)
  3.5 Heaps (min-heap, max-heap, heapify)
  3.6 Priority Queue using Heap
  3.7 Tries (prefix tree, word search applications)
  3.8 Union-Find / Disjoint Set
  3.9 Segment Tree & Fenwick Tree (BIT) basics
  🏆 Final Boss: Tree + Heap combined problem

LEVEL 4 — GRAPHS
  4.1 Graph Representation (adjacency list/matrix)
  4.2 BFS
  4.3 DFS
  4.4 Topological Sort
  4.5 Shortest Path — Dijkstra
  4.6 Shortest Path — Bellman-Ford & Floyd-Warshall
  4.7 Minimum Spanning Tree (Prim's & Kruskal's)
  4.8 Strongly Connected Components (Kosaraju/Tarjan)
  🏆 Final Boss: Real-world pathfinding problem (e.g., network delay time)

LEVEL 5 — ALGORITHMIC PARADIGMS
  5.1 Sorting Basics (bubble, selection, insertion) — animated comparisons
  5.2 Efficient Sorting (merge sort, quick sort) — animated divide & conquer
  5.3 Non-comparison Sorting (counting, radix sort)
  5.4 Binary Search + Variations
  5.5 Binary Search on Answer
  5.6 Greedy Algorithms
  5.7 Divide & Conquer
  5.8 Backtracking Basics (permutations, combinations, subsets)
  5.9 Backtracking Advanced (N-Queens, Sudoku Solver)
  5.10 Dynamic Programming — 1D (Fibonacci, climbing stairs)
  5.11 Dynamic Programming — 2D (grid problems, LCS)
  5.12 Knapsack Patterns (0/1, unbounded)
  5.13 DP on Strings (LIS, edit distance)
  5.14 DP on Trees/Graphs/Bitmask DP (intermediate-advanced)
  🏆 Final Boss: Classic interview DP problem (e.g., word break, coin change)

LEVEL 6 — ADVANCED/INTERMEDIATE (unlocks after Level 5 fully cleared)
  6.1 Advanced Graphs (bipartite check, A* intro)
  6.2 Network Flow Basics
  6.3 String Algorithms — KMP & Z-Algorithm
  6.4 String Algorithms — Rabin-Karp & Manacher's
  6.5 Advanced DP Optimizations
  6.6 System Design Basics for Coding Interviews
  🏆 Final Boss: Mixed mock-interview style problem set (timed contest mode)

Each Sublevel's theory/code/examples must include:
1. Beginner-friendly theory (simple analogies, real-world examples)
2. Step-by-step animated visualization
3. Dry run/trace table (variable states at each step)
4. Code implementation in C, C++, Java, and Python (tabbed view)
5. Time & Space Complexity analysis with explanation
6. Common mistakes & edge cases
7. Practice problems (easy → medium → boss, per stage structure above)
8. Quiz (3-5 MCQs + dry-run prediction questions)
