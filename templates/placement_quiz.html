What is the time complexity of binary search in a sorted array?

Assume you are given a sorted array of n elements. You repeatedly divide the search interval in half.

// Target lookup implementation

int binarySearch(int arr[], int l, int r, int x) {

while (l <= r) {

int m = l + (r - l) / 2;

if (arr[m] == x) return m;

if (arr[m] < x) l = m + 1;

else r = m - 1;

}

return -1;

}
