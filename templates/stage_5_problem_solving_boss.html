STAGE 8: DUTCH NATIONAL FLAG PARTITION

Given an array nums containing n objects colored red, white, or blue, sort them in-place such that items of the same color are adjacent, in order: red (0), white (1), and blue (2).

verified_user You must solve this in one single pass using only O(1) extra auxiliary memory. Library sort functions are strictly banned.
EXAMPLE 1: NORMALIZED CASE
Input: nums = [2, 0, 2, 1, 1, 0]
Output: [0, 0, 1, 1, 2, 2]
State: Red(0,0), White(1,1), Blue(2,2) partition locked
EXAMPLE 2: MINIMAL EDGE CASE
Input: nums = [2, 0, 1]
Output: [0, 1, 2]
CONSTRAINTS & INVARIANTS:
  • n == nums.length where 1 <= n <= 300
  • nums[i] is strictly 0, 1, or 2
  • Space Complexity: Strictly O(1) auxiliary memory
  • Time Complexity: Strictly O(N) single-pass pointer movement
